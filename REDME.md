# 💡 LuminaCAD — Parametric 3D Lamp Shade Studio

![Three.js](https://img.shields.io/badge/Three.js-WebGL-black?style=flat-square&logo=three.js)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow?style=flat-square&logo=javascript)
![3D Printing](https://img.shields.io/badge/Export-Binary_STL-orange?style=flat-square)
![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)

An interactive, browser-based **Parametric 3D CAD Web Application** designed for modeling custom 3D-printable lamp shades in real time. Built using **Three.js (WebGL)**, custom GLSL subsurface light shaders, and a watertight **Binary `.STL` mesh generator**.

🔗 **[Live Demo: Click Here to Try It Out!](https://YOUR_GITHUB_USERNAME.github.io/lumina-3d-studio/)**

---

## ✨ Key Features

- **Real-Time Parametric Engine:** Dynamically control height, top/bottom radius, wall thickness, radial bulge, and S-curve harmonic inflection.
- **Procedural Surface Patterns:** Generate Sine waves, Origami pleats, Architectural scallops, Lotus petals, and Mechanical gear ribs with adjustable twist, diamond knurling, and herringbone symmetry.
- **Lithophane vs. Constant Shell:** Switch between constant wall thickness or lithophane carving for custom light modulation.
- **3D-Printable Socket Mounts:** Built-in support for standard bulb fittings (**E27, E26, E14, IKEA Hemma**) with customizable spider spokes and collar rims.
- **Subsurface Light Simulation:** Custom Beer-Lambert law shader simulating warm light diffusion through varying 3D-printed wall thicknesses.
- **Watertight Binary `.STL` Export:** Directly exports slicer-ready (Cura, PrusaSlicer, Bambu Studio) Z-up binary STL files from the browser.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (ES6+)
- **3D Graphics Engine:** Three.js (WebGL, OrbitControls, Custom Shader Modification)
- **Geometry & Export:** Cylindrical-to-Cartesian Procedural Mesh Generation, `ArrayBuffer` & `DataView` for Binary `.STL` encoding.
